# Hermes Public Party-Pack Bundle (v1)

This folder is the **canonical public Hermes party-pack bundle** intended to be zipped and shipped as a single unit.

It ships **both** modules together:

- **FOAM** (`foam/`): tone / composition / behavioral “drug” layer (how Hermes speaks, moves, anchors, and modulates state).
- **Doomscroll** (`doomscroll/`): posting + cron behavior layer (how Hermes reads/posts/schedules activity on doomscroll).

## FOAM entrypoints

- Default balanced cut: `foam/SKILL.md`
- Stronger alternative: `foam/variants/extreme.md`
